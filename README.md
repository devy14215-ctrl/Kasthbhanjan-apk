# Shree Kashtbhanjan Motors — APK Source

## Project structure
- `www/index.html` — original uploaded app, renamed to `index.html`
- `package.json` — Node.js and Capacitor dependencies
- `capacitor.config.json` — Capacitor app configuration
- `README.md` — this file

## Notes
- The original HTML app is preserved; app logic and UI have not been intentionally changed.
- Capacitor web directory is configured as `www`.
- GitHub Actions APK build workflow is intentionally not included yet. Add it when requested.
- For an Android APK build, install dependencies and add the Android platform with Capacitor, then build the Android project.
